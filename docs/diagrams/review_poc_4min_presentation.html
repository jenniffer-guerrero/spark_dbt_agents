1. Business Objective and Scope

Objective

  • Compute and maintain REL_ID to REL_ID_REGIE_KLANT mapping incrementally.
  • Avoid full recomputation by recalculating only impacted graph components.
  • Preserve deterministic assignment under multi-seed reachability.

Scope Delivered in POC

  • Historical edge connectivity from direct_bank and ggm_np.
  • Active-seed eligibility restricted to direct_bank Y plus open-ended validity.
  • Parity across Python logic, notebooks, unit tests, notebook tests, and diagrams.
2. What Was Built
Phase 1

Normalize Inputs

Clean keys, preserve historical edges, and build active-seed set from direct_bank.

Phase 2

Detect Delta

Compare current edges and seeds against state snapshots.

Phase 3

Impact Expansion

Traverse graph from changed nodes to identify impacted rel_id set.

Phase 4

Seed Reachability

Expand seed-to-rel pairs and apply deterministic tie-breaker.

Phase 5

Merge Output

Replace impacted rows only and keep unimpacted output rows unchanged.

Phase 6

Persist State

Write output plus snapshots and audit metrics for next incremental run.
