siebel_id_test — Stateful case-driven validation

Runs the incremental update on real shared tables, mutating sources one case at a time and asserting exact output deltas.

Sequential & stateful — tables evolve across all 8 cases  ·  reset_sequence_to_baseline() for full replay
Setup
📦
Phase 1
Load Update Logic
Reads siebel_id_update.ipynb as JSON.
Executes all code cells into globals().
Confirms run_incremental_update is callable — no nbformat needed.
📸
Phase 2
Baseline
Loads fixture CSVs from use_cases/siebel_id/input/ into shebang tables.
Snapshots current state.
reset_sequence_to_baseline() restores tables + clears all state_db snapshots.
⚙️
Phase 3
Initialize
Resets to baseline.
Runs first incremental sync (full compute — no prior state).
Validates output against output.csv fixture.
Shows baseline tables and stats.
Per-Case Execution Loop
↺ repeated for each of the 8 cases
✏️
Mutate Sources
Insert, update, or duplicate rows in
shebang.direct_bank or shebang.ggm_np
using staging-swap writes
(safe on local Parquet).
🔄
Run Incremental Update
Calls run_incremental_update() from the loaded update notebook.
Only impacted rel_ids are reprocessed.
Returns observability stats.
🔍
Assert Delta
Computes pair_set(output) before and after.
Asserts exact inserted and removed pairs.
Asserts no duplicate REL_ID in output.
Shows full tables.
✅
Pass / Repair
PASS — case complete, move to next.
FAIL (logic) — invoke data agent to patch update notebook, reload, retry (max 2×). agent repair loop
UNRESOLVED — logged, continue.
8 Test Scenarios — run in sequence on the same shared tables
Case 1
New active seed
Insert a new Y-flagged direct_bank row with open-ended date
Case 2
Seed deactivated
Flip drc_bnk_f from Y → N; mapped rel_ids must be removed from output
Case 3
rel_id reassigned
Change ggm_np.rel_id for an existing ikb_no; old row removed, new row added
Case 4
Idempotent rerun
No mutation — run twice; expect exactly zero inserted and removed pairs
Case 5
New edge, same seed
Add new ikb_no for existing rel_id; output row stays, no delta expected
Case 6
Duplicate source row
Insert exact duplicate in ggm_np; output must not gain a duplicate pair
Case 7
New rel_id, shared key
New ggm_np rel_id reuses existing ikb_no; inherits same seed via graph
Case 8
Cross-table insert
New seed in direct_bank + new rel_id in ggm_np share the same identifier
